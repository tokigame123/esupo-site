ESUPO / PRIVACY POLICY個人情報保護方針

プライバシーポリシー

合同会社えーすぽは、個人情報を大切に取り扱います。

1. 基本方針

合同会社えーすぽ（以下「当社」）は、当社ウェブサイト（以下「本サイト」）を通じて取得する個人情報を、個人情報保護法その他の関係法令に従い、適切に取り扱います。

2. 取得する情報と利用目的

お問い合わせの際に、お名前、メールアドレス、お問い合わせ内容など、お客様からご提供いただいた情報を取得することがあります。取得した情報は、次の目的に利用します。

  • お問い合わせへの回答、ご連絡および対応のため
  • ご相談いただいた事業・サービスに関するご案内のため
  • 対応内容の確認およびサービスの改善のため

3. 個人情報の管理

当社は、取得した個人情報への不正アクセス、漏えい、紛失等を防止するため、取扱いに必要な範囲でアクセスを管理するなど、適切な安全管理に努めます。利用目的の達成に必要な期間保管し、不要となった情報は適切に削除または廃棄します。

4. 第三者への提供

当社は、法令に基づく場合などを除き、ご本人の同意なく個人データを第三者へ提供しません。業務を委託する場合は、利用目的の達成に必要な範囲で取り扱いを委託し、委託先を適切に監督します。

5. 開示・訂正等のご請求

ご本人から、当社が保有する個人データの利用目的の通知、開示、訂正、追加、削除、利用停止、消去または第三者提供の停止等についてご請求いただいた場合は、ご本人であることを確認したうえで、法令に従い対応します。手続きについては、下記の窓口へお問い合わせください。

6. 外部サービスについて

本サイトの公開には GitHub Pages を利用しています。GitHub はセキュリティを目的として、訪問者の IP アドレスを記録・保存します。詳しくは GitHub Pages のデータ収集についてをご確認ください。

本サイトの文字表示には Google Fonts を利用しています。フォントの読み込み時には、ご利用のブラウザから Google のサーバーに接続され、IP アドレス等の接続情報が送信される場合があります。詳しくは Google のプライバシーポリシーをご確認ください。

本サイトからリンクしている外部サイトでの情報の取扱いについては、それぞれのサイトの方針をご確認ください。

当社は、法令の改正や本サイトの運営内容の変更等に応じて、本ポリシーを見直すことがあります。変更後の内容は本ページに掲載します。
